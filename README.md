# 컴퓨터활용능력 2급 실기 자동 채점 프로그램

컴퓨터활용능력 2급 실기 연습, 모의문제 풀이, 그리고 정답/제출 엑셀 파일(`.xlsx`) 비교 채점을 지원하는 웹 애플리케이션입니다.

## 주요 기능

- **실기 채점 포털 (`index.html`)**
  - 회차 선택, 실습 파일 다운로드 (`해당회차 다운` / `전체 다운 (ZIP)`), 드래그 앤 드롭 엑셀 채점
  - 작업별 상세 점수 (`기본작업`, `계산작업`, `분석작업`, `기타작업`) 및 감점 내역 분석 표
  - 학생·선생님 누적점수 순위 차트, 점수별 통계보기, 동영상 강좌 가이드, 40분 실전 타이머
  - 로그인 / 회원가입 / 내 점수 기록 및 **모의문제 풀기** (객관식 + 수식 입력 즉시 채점)
- **정답 vs 내 답안 1:1 비교 채점기 (`auto_grader.html`, `grade_excel.py`)**
  - Python `openpyxl` 기반 값 범위 + 수식(함수 이름 및 결과값) 비교 채점
  - 결과 보고서 다운로드 (`결과 저장하기 (.txt)`, `엑셀 저장 (.csv)`)

## 실행 방법

```bash
pip install openpyxl
python server.py
```

실행 후 브라우저에서 아래 주소로 접속하세요:
- 전체 포털: `http://127.0.0.1:8000/index.html`
- 정답 비교 채점기: `http://127.0.0.1:8000/`
